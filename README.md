# Ge'orama

A premium, Linux-native fantasy map editor. Opens every Wonderdraft map, matches the look, and goes further. A *georama* is a hollow globe with the world mapped on the inside — you stand inside your world.

**Status:** early development. Phase 0 (foundation and first light) is in progress.

- `docs/FORMAT-wonderdraft-map-v15.md` — decoded `.wonderdraft_map` format, verified byte-exact on the owner's own maps.
- `docs/DEV.md` — setup, gates and conventions.
- `docs/SECURITY.md` — threat model and the boundary checks.

Package/command name: `georama`. Display name: Ge'orama.
