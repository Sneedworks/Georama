## 2. Conventions (v0)

These are assumptions. Stage A does not verify them. The 0.12 oracle or a reference export must confirm them before stage B relies on them.

- Rotation θ is in radians, counter-clockwise in world space.
- Mirror is a horizontal flip of the texture about its centre.
- Offset is in texture pixels, applied after mirror and before scale and rotation.

Transform. A texture point p has x in [−w/2, w/2] and y in [−h/2, h/2], where (w, h) is the atlas placement size. Let c = cos θ and s = sin θ; R = [[c, −s], [s, c]]; S = diag(sx, sy) with the signed scale components; F = diag(f, 1) with f = −1 if mirror and +1 otherwise; o = (ox, oy) the offset. The world point is `position + R·S·(F·p + o)`. So A = R·S·F and t = position + R·S·o:

- A00 = c·sx·f, A01 = −s·sy, A10 = s·sx·f, A11 = c·sy;
- tx = px + c·sx·ox − s·sy·oy, ty = py + s·sx·ox + c·sy·oy.

Placeholders: A = I and t = position. The placeholder quad is 16 × 16 world units, centred on the position.

Draw order: ascending by (zIndex, position.y, original index).

Unapplied in v0: `sample` and `customColors` are not drawn, but they are counted. `customColorMode`, `radius` and `type` are neither drawn nor counted, because the v0 `SymbolInput` does not carry them; they are future fields. A value counts as absent when it is `null` or `undefined`.

Rules are numbered; the tests cite the numbers.

**Texture classes (T)**

- T1. A string is passed to `resolveRef('symbol', text)`. Success gives `{class:'asset', key: assetKey(ref), ref}`. A `RefError` gives `{class:'invalid', code: error.code}`. Any other thrown value propagates unchanged.
- T2. A non-null, non-array object gives `{class:'embedded'}`.
- T3. Anything else (null, undefined, number, boolean, bigint, symbol, function, array) gives `{class:'invalid', code:'TYPE'}`.

**Atlas (A)**

- A1. Check order: (a) more than 1,000,000 items gives INPUT; (b) options: `maxSide` not an integer in [32, 16384], `maxPages` not an integer ≥ 1, or `padding` not an integer ≥ 0 gives INPUT; (c) per item in input order: a key that is not a non-empty string, a width or height that is not an integer ≥ 1, or a duplicate key gives INPUT. Messages name the rule, never a value.
- A2. An item with width > maxSide or height > maxSide is not placed. Its key goes to `oversize`, sorted by key ascending.
- A3. Packing. The other items are sorted by height descending, then width descending, then key ascending (JavaScript string order). Page 0 starts with the reserved block at (0, 0), 16 × 16, and its shelf start x is 16 + padding. Every other page has shelf start x = 0. Each page starts with no shelf. For each item (w, h), with the page state (top, shelfH, x):
  1. If the page has a shelf and x + w ≤ maxSide, place at (x, top) and set x += w + padding. The vertical fit holds because h ≤ shelfH by the sort order.
  2. Otherwise open a shelf: newTop = top + shelfH + padding if the page has a shelf, else 0; newX = the shelf start x. If newX + w ≤ maxSide and newTop + h ≤ maxSide, set top = newTop, shelfH = h, x = newX, place at (x, top), then x += w + padding.
  3. Otherwise open the next page, index + 1. If that index is ≥ maxPages, return LIMIT. Else place at (0, 0) with top = 0, shelfH = h, x = 0, then x += w + padding. Oversize items were removed, so this always fits.
- A4. Output: `pageSize = maxSide`; `pages` = the number of pages (page 0 always exists); `reserved = {key:'', page:0, x:0, y:0, width:16, height:16}`; `placements` in packing order. Empty items are valid: pages <redacted> placements [], oversize [].

**Instances (I)**

- I1. Check order: (a) more than <redacted> symbols gives INPUT, checked before iterating. (b) Per symbol in index order: position.x, position.y, rotation, scale.x, scale.y, offset.x and offset.y must be finite numbers; zIndex must be an integer; mirror must be a boolean. Otherwise INPUT, naming the field and the index.
- I2. Each symbol is classified by `classifySymbolTexture`. `asset` with a key in `atlas.oversize` gives placeholder `oversize`. `asset` with no placement for its key gives placeholder `unresolved`. `asset` with a placement gives a sprite. `embedded` gives placeholder `embedded`. `invalid` gives placeholder `invalid`.
- I3. Sprite record: A and t as in section 2, with (u0, v0, w, h, page) from its placement and colour (1, 1, 1, 1).
- I4. Placeholder record: A = I, t = position, (u0, v0, w, h, page) = (0, 0, 16, 16, 0) from `atlas.reserved`. Colours: embedded (0, 1, 1, 1); invalid (1, 0, 1, 1); unresolved (1, 1, 0, 1); oversize (1, 0.5, 0, 1).
- I5. `records` holds 16 floats per symbol, in draw order: [A00, A01, A10, A11, tx, ty, u0, v0, w, h, page, r, g, b, a, 0]. Units are atlas pixels; the GPU stage divides by `pageSize`.
- I6. `order[k]` is the original index of the k-th drawn symbol, sorted by (zIndex, position.y, index).
- I7. `counts.total = symbols.length`. Sprites plus the four placeholder counts equal the total. `unapplied.sample` counts symbols whose `sample` is neither `null` nor `undefined`; `unapplied.customColors` counts symbols whose `customColors` is neither `null` nor `undefined`. v0 does not validate `sample` or `customColors`.

## 4. Hand-computed examples (the tests assert these exact values)

- **E1 (packing with padding).** Options {maxSide 64, maxPages 1, padding 1}; items c(10×10), a(20×30), b(20×30), given in that input order. Result: a at (17, 0); b at (38, 0); c at (17, 31); pages 1; oversize []. Trace: a opens the first shelf at (17, 0) with shelfH 30 and x 38; b fits at (38, 0) and x becomes 59; c does not fit (59 + 10 > 64), so a new shelf opens at top 30 + 1 = 31 with x 17.
- **E2 (new pages).** Options {maxSide 32, maxPages 3, padding 0}; items d(20×20), e(20×20). Result: d on page 1 at (0, 0); e on page 2 at (0, 0); pages 3. Trace: on page 0 the shelf start is 16 and 16 + 20 > 32, so d goes to page 1. On page 1, e would need a shelf at top 20, and 20 + 20 > 32, so e goes to page 2.
- **E3 (limit).** E2 with maxPages 2 gives LIMIT, because e would need page index 2.
- **E4 (oversize).** Options {maxSide 32, maxPages 1, padding 0}; items f(33×8), g(8×8). Result: oversize ['f']; g at (16, 0) on page 0; pages 1.
- **E5 (transform).** Texture 16 × 16 at position (100, 50). Rotation 0, scale (2, 1), offset (0, 0), no mirror gives A = diag(2, 1) and t = (100, 50). Mirror gives A00 = −2. Rotation π/2 with scale (1, 1) gives A ≈ [[0, −1], [1, 0]]. Offset (3, 4) with scale (2, 1) and rotation 0 gives t = (106, 54).

CPU trigonometric and float32 values are compared with `toBeCloseTo(v, 6)`, never with `toBe`: A01 is −0 when the rotation is 0, and `toBe` distinguishes −0 from <redacted> Placements, codes, counts, orders and colours are compared exactly.
